Project Overview
A personal, self-hosted media tracking app to replace Trakt.tv
🔐

Auth-Gated

JWT login from day one. Single admin user; multi-user extensible via user_id FK already on all data tables.

🎞️

Movies & TV

Track movies and episodic TV. Mark individual episodes or full seasons watched in one action.

📊

Rich Stats

Global stats + per-series progress. Date-range history page. Hours remaining per in-progress queue.

🔄

Auto-Sync

APScheduler syncs new episodes for returning shows twice weekly. Fully containerised, no external cron needed.

📋 watch_history Design Notes

Append-only ledger

Every "Mark Watched" inserts a new row with watched_at timestamp. Full history is preserved.

Unwatch = DELETE row

Removing a watch event deletes the specific history row. The movie/episode stays in the library.

Mutual exclusivity

Either movie_id OR episode_id is set per row — never both. Enforced at the API layer.

Optional rating & note

Rating (1–5 INT nullable) and note (TEXT nullable). Only saved when user provides them.

🔢 Stats Query Strategy

StatApproach
Movies watchedCOUNT DISTINCT movie_id WHERE movie_id IS NOT NULL
Total movie hoursSUM(movies.runtime_mins)/60 via JOIN
Episodes watchedCOUNT DISTINCT episode_id WHERE episode_id IS NOT NULL
Total TV hoursSUM(episodes.runtime_mins)/60 via JOIN
In-progress seriesShows with ≥1 watched episode AND remaining episodes > 0
Hours remainingSUM(unwatched episode runtime_mins)/60

Background Sync — APScheduler
In-process scheduler. No Redis, no cron, fully containerised.

⏱ Configuration

Type: AsyncIOScheduler (APScheduler 3.x)

Schedule: Cron — Tuesday & Friday, 02:00 UTC

Lifecycle: Started on FastAPI startup, stopped on shutdown

Manual trigger: POST /api/admin/sync

Missed run on restart: Harmless — sync will run at next scheduled time

🔄 Sync Job Steps

Query DB

SELECT all tv_shows WHERE status = "Returning Series"

Fetch TMDB

GET /tv/{tmdb_id} and new season details for each show

Upsert Seasons & Episodes

INSERT new seasons/episodes; update show status if Ended

Timestamp

UPDATE tv_shows SET last_synced_at = NOW()

Deployment Architecture
Single container. Host Nginx handles SSL and static serving.

🐳 Docker Setup

Single Container

FastAPI + APScheduler. Host port 8020 mapped to container port 8020.

Named Volume

mediatracker-data → /data/mediatracker.db. Persists across restarts and updates.

Env Variables

TMDB_API_KEY, SECRET_KEY, DATABASE_URL passed at runtime via .env file.

Restart Policy

restart: unless-stopped — survives VPS reboots automatically.

⚡ Nginx Config Strategy

Static Frontend

Nginx serves Vue dist/ from /var/www/mediatracker/. SPA fallback to index.html.

API Proxy

All /api/* → http://localhost:8020. No CORS — same origin from browser perspective.

SSL / HTTPS

Certbot manages Let's Encrypt on host Nginx. Docker speaks plain HTTP internally.

No Subdomain (yet)

Can be added as a new Nginx server block later with zero application changes.
